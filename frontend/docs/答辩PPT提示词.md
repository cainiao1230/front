## 第2页：项目背景与意义（40秒）

### 背景
- 我国已进入深度老龄化社会，60岁以上人口超3亿
- 传统养老机构面临管理效率低、信息不透明、护理调度混乱等问题
- 纸质记录易丢失、床位分配全凭经验、护理任务难追踪

### 意义
- **社会价值**：提升养老服务质量，让老人享受更专业的照护
- **管理价值**：实现床位、护理、用药的数字化管理，降低运营成本
- **技术价值**：构建可扩展的前后端分离架构，为智慧养老提供技术示范

---

## 第3页：系统架构与技术选型（35秒）

### 技术栈
- **前端**：Vue 3 + Vite + Element Plus + Vue Router
- **后端**：Spring Boot + MyBatis + MySQL（后端同学负责）
- **架构**：前后端分离、RESTful API、JWT认证

### 系统角色
- **管理员(admin)**：全功能权限，系统配置
- **护士(nurse)**：老人护理、任务执行、用药管理
- **护工(caregiver)**：日常护理任务执行
- **家属(family)**：查看老人信息（预留）

---

## 第4页：核心功能模块（60秒）

### 🏠 运营仪表盘
- 实时统计：在院老人数、床位使用率、今日任务数
- 今日护理安排：任务列表、状态筛选、快速操作
- 安全预警：异常情况实时提醒

### 👴 老人管理
- 入住申请→审批→分配床位 完整流程
- 老人档案：基本信息、护理等级、紧急联系人
- 支持搜索、筛选、详情查看

### 🛏️ 床位管理
- 三步式床位分配向导：选老人→选床位→确认分配
- 楼层可视化：按楼层查看床位使用情况
- 床位调整历史记录追溯

### 📋 护理管理
- 护理任务：创建、分配、执行、完成全流程
- 护理记录：记录每次护理详情
- 用药管理：用药提醒、服药确认

### ⚙️ 系统管理
- 用户管理：账号创建、角色分配、状态控制
- 角色权限：RBAC权限控制，43项细粒度权限
- 操作日志：关键操作留痕，可追溯

## 常见问题准备

### 1. 为什么选择Vue3？
- 性能更好，响应式系统重构
- Composition API更灵活，代码组织更清晰
- 生态成熟，Element Plus支持完善

### 2. 权限如何实现？
- 前端：路由守卫 + meta.permissionCode 控制页面访问
- 后端：接口级权限校验，双重保障
- 按钮级：v-if 结合权限码控制操作按钮显示

### 3. 遇到的最大困难？
- 前后端接口对接，字段命名、数据格式统一
- 权限体系设计，需要考虑多角色多场景
- 响应式数据处理，复杂表单状态管理

### 4. 如何保证数据安全？
- JWT Token认证，请求头携带Authorization
- 接口权限校验，无权限返回403
- 敏感操作二次确认（删除、审批等）
- 前端表单校验 + 后端数据校验双重保障
